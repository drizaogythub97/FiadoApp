# Post LinkedIn — FiadoApp

---

Meu pai tem um comércio de bairro e ainda controlava tudo no caderninho. Quem devia, quanto devia, quando vencía — tudo à mão. Cobranças esquecidas, histórico perdido.

Resolvi isso construindo o **FiadoApp**: um sistema completo de gestão de vendas a prazo, pensado para comerciantes de bairro, ambulantes e feirantes. Simples o suficiente para qualquer pessoa usar, completo o suficiente para substituir o caderninho de vez.

**O que o sistema entrega:**
→ Cadastro de clientes e registro de vendas a prazo
→ Dashboard com total a receber, inadimplentes e vendas ativas em tempo real
→ Quitação total, parcial ou selecionada — com comprovante em PDF gerado na hora
→ Histórico completo por cliente e relatórios exportáveis
→ App Android com sessão persistente e compartilhamento nativo de documentos

**Stack do projeto:**
→ PHP 8 + MySQL (PDO) no back-end, sem framework
→ CSS com design system próprio — tema escuro, responsivo, mobile-first
→ Android nativo em Java com WebView + CookieManager para sessão persistente
→ CI/CD com GitHub Actions — deploy automático via FTPS para a Hostinger
→ Credenciais protegidas via GitHub Secrets
