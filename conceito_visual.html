01 — Embasamento
O que os melhores apps financeiros fazem hoje
Análise de tendências de UX/UI em apps de controle financeiro, rastreadores de despesas e ferramentas de gestão para pequenos negócios (2024–2025).
🌑

Dark Mode como padrão

Apps como Dime, MoneyLover e Wallet adotaram dark mode como interface principal. Reduz fadiga visual em uso prolongado e dá aparência premium. Pesquisas mostram aumento de 15% no tempo de sessão.

Tendência forte
📦

Cards com hierarquia clara

Informações agrupadas em cards bem definidos, com 2–3 níveis de destaque visual. A informação mais importante (valor, nome, status) sempre em destaque. Dados secundários em cor rebaixada.

Visual
🏷️

Badges e status visuais

Status ATIVA/PAGA exibidos como badges coloridos (não texto puro). Verde = pago/positivo, vermelho/âmbar = pendente. O usuário identifica o estado com um olhar, sem ler.

Visual
📐

Espaçamento generoso

Margens e paddings maiores, especialmente em mobile. Touch targets mínimos de 44px. Elementos com espaço para "respirar". Elimina sensação de tela congestionada.

Visual
🎯

Ação principal em destaque

A ação mais importante de cada tela tem o botão mais destacado. As ações secundárias são claramente subordinadas. Hierarquia: primário > ghost > link. Sem dois botões vermelhos na mesma tela.

Estrutura
📱

Mobile-first genuíno

Grids de botão em coluna (não linha) no mobile. Área de toque adequada. Inputs com font-size ≥ 16px (evita zoom automático no iOS). Navegação com itens acessíveis pelo polegar.

Estrutura
02 — Paleta de Cores
Duas opções — minha recomendação e alternativa
Analisei o perfil de uso do FiadoApp: ambiente de loja, uso rápido, usuário não-técnico. A paleta precisa ser confortável, familiar e funcional.

Por que esta? Mantém o vermelho da marca sem alteração — nenhuma mudança na logo necessária. O fundo escuro (#141418) faz o vermelho "brilhar" naturalmente, criando contraste poderoso. O charcoal quente evita a frieza do preto puro. Esta opção é a mais rápida de implementar e a menos arriscada para o lançamento.

03 — Tipografia
Inter — fonte recomendada
A Segoe UI atual é excelente no Windows mas não carrega em outros SOs com o mesmo resultado. A Inter é gratuita (Google Fonts), projetada para interfaces digitais, carrega perfeitamente no Android para o futuro WebView, e é visualmente muito próxima da Segoe UI — a transição será imperceptível para o usuário.

04 — Componentes
Novo sistema de design — botões, badges e inputs
Cada componente redefinido com hierarquia clara. A regra principal: cada tela tem apenas um botão primário (vermelho) — todas as outras ações são secundárias ou ghost.

Botões

Primário (vermelho) = 1 por tela, ação principal.
Verde = confirmar pagamento/quitação.
Ghost = navegação e ações secundárias.

06 — Mudanças Estruturais (opcionais)
Pequenas melhorias que casam com o novo visual
Não são obrigatórias para o lançamento, mas melhoram a experiência sem exigir mudanças no banco de dados ou na lógica de negócio.
📅

Formatação de datas

Todas as datas exibidas no formato brasileiro dd/mm/aaaa. Mudança simples em PHP com date('d/m/Y', strtotime($data)).

Correção de bug
💬

Toast notifications melhoradas

As toasts atuais já são boas. Ajuste visual: ícone maior, cantos mais arredondados, background alinhado ao dark theme. Comportamento mantido.

Cosmético
🔢

Formatação monetária

"R$ 166.50" → "R$ 166,50". Ajuste em JS (toLocaleString('pt-BR')) e em PHP (number_format($v,2,',','.')).

Correção de bug
📱

viewport meta nas páginas faltantes

3 páginas estão sem a tag — isso significa que o mobile renderiza como desktop comprimido. Correção de 1 linha por arquivo.

Correção de bug
🏷️

Badges de status nos relatórios

Os resultados de relatório mostram "Status: ATIVA" em texto puro. Com badges coloridos, o usuário identifica o status de cada venda de relance sem ler.

Cosmético
🖼️

Footer em todas as páginas

2 páginas sem footer criam inconsistência visual. Adição simples de um componente já existente no projeto.
